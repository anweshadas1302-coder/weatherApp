# 🌤️ weatherApp
### Your city. Your weather. One search away.

A simple weather app that lets users look up the weather for an entered city. Built around a straightforward idea: make checking the weather quick and easy.

Whether you're checking your hometown or exploring somewhere new, start with a city name and let the forecast guide your next move.

## 🎯 Project Focus
- Search for weather by city name.
- Practice building a weather-focused web interface.
- Develop frontend styling skills with CSS.
